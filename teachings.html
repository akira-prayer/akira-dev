浄化浄霊への理解を深めるために

師の教え 壱

師の動画（ジャスミン セカンドチャンネル）を自分用にまとめたメモです。許可頂きましたので転載します。

徳を積む・隠徳について

1. 徳を積むとは

  • 誰かのためになる行いをすること。
  • 特に、人に見られないところで行う「隠徳（いんとく）」が最も良い。

2. 隠徳の具体例

  • 公共のトイレを綺麗にして出る
  • 道に落ちているゴミを拾う
  • 倒れた自転車を起こす
  • 落ちている小銭を綺麗にして募金箱へ入れる
  • 落とし主が見つかれば返す

これらはすべて、思いやり・優しさ・誠実さの波動を高める行為。

3. 隠徳がもたらす効果

  • 波長・波動が大きく上がる
  • 心が穏やかになる
  • 神様・仏様が必ず見てくださっている

4. やってはいけないこと

  • ゴミのポイ捨て
  • 唾を吐く
  • 公共の場所を汚す行為

理由：すべての土地は神様の場所という考え方があるため。

5. 大切なのは「見返りを求めない心」

  • 「良いことが起きるからやる」ではなく、純粋に誰かのために行うことが大事。
  • その行為が自分の心を浄化し、人生を良い方向へ導く。
心の状態を変えて人生を良くする方法

1. 未来は「心の状態」がつくる

  • 目の前の出来事は心の中の状態がタイムラグを経て現実化したもの。
  • 心が穏やかなら、未来も穏やかになる。
  • イライラ・不安・怒りが続くと、後からそのような現象が起きる。

2. 言葉（言霊）も未来をつくる

  • 良い言葉 → 良い未来
  • 悪い言葉 → 悪い未来・体調不良
  • 自分に向ける言葉も他人に向ける言葉も、すべて現実化に影響する。

3. 心を穏やかに保つのは“最難関の修行”

  • 霊体・生き霊・人間関係の攻撃など、外的要因で乱れやすい。
  • それでもどんな時でも心を穏やかに保つことが最大の修行。

4. 怒りのコントロールが最重要

  • 深呼吸、肩を回す・軽く体を動かす、好きな音楽を聴く、真言を唱える

怒りを放置すると波動がどんどん悪化するため、“最初の小さな怒り”の段階で止めることが鍵。

5. 不安の対処法

  • 深呼吸
  • プラスの言葉を大量に唱える（「幸せ」「大好き」「ありがとう」など）
  • 何百回でも良い。波動が一気に上がる。
片付けが浄化になる理由と実践方法

1. 片付けは“浄化”そのもの

  • 家に不要な物があると気が滞り、邪気を吸いやすくなる。
  • 使っていない物・古い物は早めに手放すのが良い。

2. 片付けの進め方

  • 期間を決めて一気にやる（例：1ヶ月以内）。
  • 1日で全部やらず、1スペースずつ（今日はクローゼットだけ、など）。
  • 物は「いる」「いらない」「迷う」に分け、いらない＋迷う＝手放す。

3. 生霊対策としての片付け

生霊に悩んでいる人は特に重要。

  • 生霊を飛ばしている相手からもらった物は捨てる（新しい物は売ってもOK）。
  • その人と会っていた時に着ていた服も手放す。布類は邪気を吸いやすいので特に注意。

4. 片付けできない日でもできること

  • 1日1〜3個、いらない物を捨てる習慣をつける。小さな物でOK。数を少なくすると続きやすい。
波動を上げる方法とクンダリーニ

1. 瞬間的に波動を上げる一番簡単な方法

  • 変な動きをする（踊る・手を上げる・ふにゃっと動く）
  • かっこよくなくていい、むしろ「変な動き」のほうが波動が上がる。1人の時にやるのがおすすめ。
  • 体を動かすことでエネルギーの流れが変わり、縮こまった波動が一気に上向く。

2. 波動が上がる理由

  • 落ち込むと体が縮こまり、エネルギーが滞る。動くことでエネルギーが上から入りやすくなる。

3. クンダリーニとは

  • 2匹の蛇がとぐろを巻いて眠っているエネルギー。
  • 肉体を切開しても見えるものではなく、別次元に存在しつつ肉体に重なっているエネルギー体。

4. クンダリーニ上昇の体感

  • 背骨を「ミシミシ」と上がるような感覚、頭の穴が開くような感覚、宙に浮くような感覚、幸福感など。

5. 上昇のタイミングと意味

  • ヒーリング中、意図した時、眠りから覚める瞬間など。霊的な力の解放・強化に繋がる。
笑いの力と波動の関係

1. 笑いは心と体に強力に効く

  • うつ・病気・心の不調に「笑い」はとても有効。苦しい時ほど笑えないのが現実。

2. 笑えない時は“意識的に笑いを取り入れる”

  • 面白い動画・お笑い・ゆるいチャンネルを見る。作り笑いでも多少効果はあるが、本当に笑うほうが波動が上がる。

3. 笑いは“邪気の浄化”になる

  • 笑うと波動が一気に上がる。体の中の邪気が嫌がって離れる。憑依・念・生霊なども笑いを嫌う。

4. 「ほっとできる時間」が未来を変える

  • ほんの数分でも心地よい時間があると、未来の現実が変わる。大笑いでなくても「ふふっ」と笑うだけで十分効果がある。
印・結界・お守りについて

1. 印（いん）について

  • 印は強力だが、中途半端に結ぶくらいなら合掌の方が安全で確実。印を結びすぎると腱鞘炎になるほど負荷が大きい。
  • 初心者は無理に印を覚えず、まず真言を大量に唱える方が良い。

2. 結界について

  • 完璧な結界はほぼ不可能。強い存在は「人に入って」侵入してくるため、結界を突破される。
  • 結界よりも“入ってきたものを浄化する力”を育てる方が重要。

3. 九字切り（くじきり）について

  • 非常に危険。プロレベルになるまで絶対にやらない方がいい。「かっこいいから」という理由で覚えるのは絶対にNG。

4. お守りについて

  • お守りは「守ってもらうもの」ではなく、神様とつながるための“媒介”。たくさん持つ必要はない。
  • 「お守りがないと不安」になると、それが“隙”になる。
自分が嫌いな人へ

1. 「自分が嫌い」は前世が必ず影響している

  • 自己否定の感情は、今世だけの問題ではなく前世の因縁・呪詛・未浄化の感情が原因。まずは意図して浄化することが大切。

2. コンプレックスは“自分だけが気にしている”ことが多い

  • 他人はそこまで気にしていない。自分を責める癖が強いだけ。浄化が進むと、自然に気にならなくなる。

3. 自己肯定感を上げる方法

  • 「自分大好き」と無理に言う必要はない。抵抗があるなら、まずは自分を褒めるところから。
  • 自分を褒める例： 「今日もよく頑張ったね」「強いね」「偉いよ」

4. 他人を褒めると、自分も変わる

  • 誰かを褒めると、その言葉は別の形で自分に返ってくる（言霊）。人の良いところが自然に見えるようになり、自分も変わる。
子どもとの向き合い方

1. 子どもの問題の多くは「親の課題」

  • 不登校、友人関係の悩みなど → 子ども自身の課題より、親の前世・因縁が原因であることが多い。
  • 親同士の嫉妬や前世の対立が、子どもに影響することも多い。

2. 解決の鍵は「親が浄化すること」

  • 子どもに直接言うより、親が相手の前世を浄化する方が効果が出る。浄化が進むと、子どもが本来の力を発揮できる。

3. 子どもへの接し方

  • ❌ 強く言う・命令する → 思春期には逆効果。何でも言うことを聞く子も危険。
  • ⭕ サポートに徹する：望むことを尊重しつつ、必要な時だけ軌道修正。

4. 子どもの未来を思い描く

  • 動画を再生する前に「〇〇が幸せになりますように」と名前を言う。リラックスした時に、子どもが幸せに過ごしている未来をリアルに想像する。
目に見える世界は「自分の内側の投影」

1. 目に見えるものは“本当は存在していない”

  • 肉体も物質も、この地球の“仮想的なルール”の中で見えているだけ。外側に見える出来事は自分の内側の状態の反映。

2. 批判している相手＝自分の内側

  • 誰かを「悪い」と批判している時、実際は自分の心の内側にあるものを批判しているだけ。

3. 批判・アンチ行為は魔が入りやすい

  • 裏で悪口を書く、匿名で攻撃する、正義感で他者を裁く → 魔・邪気が入り込む最も危険な状態。

4. 浄化の本質は「内側に気づくこと」

  • まず外側ではなく自分の内側の乱れに気づくことが先。気づけば浄化力が戻る。

5. 実践ステップ

  • 目に見える出来事で心が乱れたら「これは自分の内側の反映」と気づく。批判をやめ、内側の原因を見つめる。
歯磨き・お風呂・掃除は強力な浄化行為

1. 歯磨き・お風呂は浄化そのもの

  • 清潔にする行為は邪気・霊体が嫌う。お風呂が面倒になる／歯磨きしたくない → 憑いているサインになりやすい。

2. 清潔にすることで浄化が進む

  • 特に洗うと良い場所：耳の後ろ、首の後ろ、足の裏（邪気が落ちやすい）。

3. 部屋の状態＝心と魂の状態

  • 部屋が散らかる → 浄化が滞っているサイン。いらない物は邪気を吸うので捨てるのが最善。
ツインレイと陰陽、そして心の在り方

1. ツインレイとは

  • ツインレイの「顔」は前世の自分の顔。手・指・足など体の特徴が似ることもある。偽ツインとの時間も“必要な学び”。

2. 白龍と黒龍＝クンダリーニ（陰と陽）

  • すべての人が白龍（陽）と黒龍（陰）を持っている。陰陽のバランスが人生の安定を決める。
  • 陰陽が崩れる時：憑依・邪気・ネガティブ感情が増えると黒龍が邪気を吸いすぎて弱る。

3. 黒龍＝悪魔ではない

  • 闇（黒龍）は悪ではなく必要な力。正しい心に使われれば「強力な味方」。使い方は自分の心次第。

4. 正しい心＝中庸（フラット）

  • 真ん中（中庸）でいることが最も安全で強い。目安は「自分がされたくないことを相手にしない」「相手が嫌がる感情を自分が持たない」。
神社での参拝と「お願い事」

1. 神からの伝言：お願い事をしないでほしい

  • 神社での「お願い事」は、神々をさらに弱らせてしまう。神々はすでに限界に近い状態。

2. 参拝の基本姿勢：控えめ・静か・感謝

  • 鈴を強く鳴らすなど「大きな音」は神が嫌う。まずは「いつもありがとうございます」と感謝を伝える。

3. 祈りの内容：神を癒やす祈りへ

  • これからは「神様が楽になりますように」「幸せになりますように」と祈る。

4. 一般の人ができること

  • 浄化の修行をしていない人は「感謝」と「神が楽になりますように」の祈りだけで十分。
生霊は未来や別パラレルからも来る

1. 未来や別パラレルからの生霊

  • 時間は同時進行しているため、未来の本人や別パラレルの本人から生き霊が来ることがある。
  • 現実世界の本人に返そうとしても、未来由来だと戻らないことがある。

2. 生き霊への対応：攻撃しない・感情をぶつけない

  • 生き霊にも感情があり、強い言葉で追い払おうとすると逆効果。落ち着いて浄化し、ついている邪気だけを外す。

3. 根本解決は「因縁解消」

  • 生き霊を飛ばしている本人の前世の魂を浄化する。怒りや拒絶ではなく、浄化と因縁解消が最も有効。
ヒルコ浄化と大聖歓喜天の必要性
  • アンチコメントが入る動画＝今その真言が必要であるサイン。
  • 大聖歓喜天（ガネーシャ）の真言を唱えた直後にアンチコメントが入り、「確実に必要な真言だった」と確信。
  • 大聖歓喜天（ガネーシャ）＝タケミカヅチと対応する存在。ヒルコ浄化の流れと完全にリンクしている。
  • 鏡と刃物は“魔”が嫌う。効果があるため、お守りとして持つのは良い。
ホ・オポノポノ動画と宗教戦争の浄化
  • ショート動画に「熱い」という機械音声が混入。原因は「宗教戦争の浄化」（十字軍などで焼かれた人々）。
  • 真言を受け入れない魂も、ホ・オポノポノ（ハワイの言霊）には抵抗が少なく、浄化が届きやすかった。
  • 「熱い」音声は浄化の過程で出たもので、視聴者に悪影響はない。
晴れを引き寄せる真言と願望実現

1. 願望実現の基本原理

  • 「叶わないだろう」と思えば、叶わない未来を引き寄せる。
  • “叶った時の感情” を先に感じられれば、現実がそちらに動く。これはお金や人間関係すべてに共通する。

2. 願望実現のコツ

  • 叶った瞬間の「やった！」という感情を先に味わう。その感覚が未来を決定づける。
  • 「晴れた」「できた」「ありがとう」などの言葉（言霊）は未来を変える。
見ている“現実”はどれほど正確なのか
  • 現実を見ているのは「肉体の目」ではなく“意識体（クンダリーニ）”。
  • 現実は映画のように「自分の視点」で構成されており、意識体が必要なものだけを映し出している（鼻が見えない現象など）。
  • 現実に起きる出来事は“必要なメッセージ”。腹が立つこと・悲しいことも含めて意味がある。
  • 頑張りすぎる人は、緩めることも必要。「もう十分頑張った」と認め、流れに身を任せる時期も大切。
「いい人」をやめて自分を犠牲にしない

1. 運を悪くする最大の原因

  • 自分を犠牲にして我慢し、遠慮し続けること。自分の運を他人に譲ってしまう状態になっている。
  • 自己犠牲は「私は最後でいい」というエネルギーを発し、宇宙はそのままの現実を返してくる。

2. 今の時代に必要なこと

  • 自己犠牲をやめ、自分の意見・感情・望みを優先すること。これは“わがまま”ではなく、自分の人生を生きるための必須条件。
新種の「鬼」について
  • 最近増えている「新種の鬼」は、隠れるのが非常に上手で、入っている本人が気づきにくい。
  • 感情の暴走、人間関係の破壊、異常行動などを引き起こす。
  • 従来の魔物より浄化しにくく（話が通じない）、強い抵抗がある。「攻撃ではない」と伝えつつ、対話しながら水を使って浄化する。
  • 「最近おかしい」「周囲に異常な人がいる」と感じる人は、浄化の役目を持って生まれている可能性が高い。
ワクワクを使う引き寄せの方法
  • 仕事や使命に対してワクワクを感じるのは難しい。ワクワクは“仕事と結びついていなくていい”。
  • 1日10〜20分で十分。時間を忘れて夢中になれること（絵、楽器、手芸、ゲームなど）を見つける。
  • 「夢中になっている時のエネルギー」が宇宙に届き、別の形で現実化して返ってくる。
未来を“具体的に設定する”
  • 「いつかできたらいいな」では叶わない。未来の姿を明確にイメージし、スケジュール帳を使って1年後の自分を明確に描く。
  • 未来が具体的だと、「今やるべきこと」が自動的に浮かぶ。
  • SNSなどは最初の2ヶ月が勝負。縁起が良い日（一粒万倍日など）を開始日に設定すると行動が続きやすい。
クマ・火事・埴安彦/埴安姫のサイン
  • クマの異常行動や火事の多発は、自然破壊に対する自然界（山の神、埴安彦・埴安姫）からの警告。
  • 人間中心の価値観（命の選別など）が怒りを招いている。
  • 私たちにできることは、神に「願う」ことではなく、懴悔とお詫び。自然へのお詫びの思いが状況を変える。
人間関係の問題を繰り返す理由
  • 急激に仲良くなり、突然関係が壊れる。多くは「してもらっている側」が感謝を忘れ、怒り出すパターン。
  • これは魂の課題（お試し）。気づくまで、相手を変えて同じ出来事が起こる。
  • “怒る側”は相手の立場に立ち感謝すること。“我慢する側”は思い込みを手放し自分を大切にすることが学び。
浄化浄霊の核心（最重要ポイント）
  • 浄化は数回で終わるものではなく、複雑に絡む長期プロセス。本質は“自分で浄化できるようになること”。
  • 未浄化の魂は膨大。霊媒体質の人はその多さをそのまま受け取ってしまう。
  • 自分で浄化する方法の骨格は「意図する（最重要）」「言葉（真言・お経）」「思い（相手が楽になりますように）」。道具より心が重要。
  • 対人関係の問題は“前世の因縁”。40代以降に課題が表面化しやすい。
生き霊の仕組み・症状・対処法
  • 生き霊は亡くなった霊より厄介。飛ばしている本人が生きている限り、執着が続く限り何度でも飛んでくる。
  • 恋愛や嫉妬など、“強い執着”がある時だけ飛ぶ。受けた側は頭痛、肩こり、イライラなどの症状が出る。
  • 根本原因は前世での「因縁」。縁切り神社や生き霊返し（拒絶）は逆効果。
  • 対処法は「因縁解消」しかない。相手と自分の前世の魂を浄化し、幸せを祈ることで生霊の根が消える。

輪廻転生（転生・前世・因縁）
  • 人は何千回以上生まれ変わっており、前世の記憶は“学びを難しくするため”に消されて生まれてくる。
  • 前世で解決できなかった問題・因縁は今世に再び現れ、被害者・加害者の立場は転生で入れ替わる。
  • 因縁は前世の浄化によって解消でき、「相手の幸せを祈れる状態」になると完全に終わる。
  • 苦しい人生を選んで生まれてくる魂ほど霊力が高く、「プロの浄化者」になれる素質を持つ。
仮想現実（この世界の仕組み）
  • この世界は魂の学びのために設計された仮想空間のようなもの。現実は固定されておらず、「内側の状態（波動）」の投影。
  • 人間関係（家族や職場など）は前世からの因縁によって配置された“シナリオ”。
  • 外側を変えるのではなく、感謝・祈り・浄化で内側を整えることで現実が変わる。
  • 苦しい現実は“罰”ではなく、魂が成長するための“課題”。
日本・世界・地球
  • 日本は世界の中でも波動が高い土地であり、世界の浄化が進む時の要（かなめ）になる。
  • 世界で争いや混乱が増えているのは浄化のプロセスであり、新しい時代への移行。
  • 地球の波動が上がっているため、隠れていた因縁が浮上しやすくなっている。
  • 日本人の使命は、祈り・浄化・調和を世界に広げること。個人の祈りが地球の未来を変える。
因縁・因果
  • 因縁とは前世から持ち越した関係性で、今世の被害者・加害者関係は前世が100％原因。人間関係として最も強く現れる。
  • 因縁を終わらせる方法は「前世の浄化」。相手の幸せを祈れる状態になると完全に終わる。
  • 因果は今の感情・思考（嫉妬や感謝など）でも新たに作られる。
  • 因縁は罰ではなく魂が成長するための課題であり、今世で終わらせれば来世には繰り返さない。
嫉妬・執着
  • 嫉妬や執着は今世だけの感情ではなく、前世の経験・不足感・因縁が原因。
  • 嫉妬は「相手が悪い」のではなく、自分の内側が満たされていないサイン（他者依存）。執着は「失う恐れ」から生まれる。
  • これらは邪気を生み波動を大きく下げる。手放す方法は「浄化」と「感謝」。
  • 最終的には、他人の幸せを心から祝福でき、自分で自分を満たせる状態を目指す。
浄霊・除霊
  • 除霊は霊を「追い払う」だけで根本解決にならないが、浄霊は霊を「救い、光に還す」根本的な解決。
  • 浄霊は関わる人間の因縁も解消する、愛と祈りの行為。
  • 霊力が高く、前世で浄化者だった魂が浄霊の素質を持つことが多い。無理に行うと霊を背負う危険があるため、一般の人は浄化の意図と感謝を持つだけで十分。
生霊（いきりょう）
  • 生きている人の強い感情（嫉妬・怒り・執着・依存）が飛ぶ現象で、死霊よりも強力な場合がある。
  • 生霊は前世の因縁と深く関係しており、相手の前世と自分の前世を浄化することで根本的に解消できる。
  • 生霊は悪意ではなく「助けてほしい」という苦しみから生まれるため、責めるのではなく祈りで解消することが大切。
赦す（ゆるす）
  • 赦すとは相手を肯定することではなく、自分の心を縛る感情を手放し、心の自由を取り戻す行為。
  • 恨みや怒りを抱え続けると因縁は来世に持ち越される。赦すことで初めて因縁は解消される。
  • 無理に赦そうとするのではなく、前世の浄化が進むと自然に怒りが薄れていく（浄化の結果としての赦し）。
  • 最終的に「相手の幸せを祈れる状態」になると、魂の波動が大きく上がり現実が好転する。
徳を積む
  • 徳とは魂が持つ「光の量」。徳が多いほど運気や人間関係がスムーズになり、神仏に守られやすくなる。
  • 誰かのために祈る、感謝する、見返りを求めない行動などで徳は積まれる。逆に悪口や嫉妬は徳を減らす。
  • 徳は前世からの積み重ねでもあり、今世で積んだ徳は来世にも持ち越され、因縁を乗り越える力になる。
悪口・陰口
  • 悪口・陰口は最も波動を下げる行為であり、自分の未来を汚し、生霊となって相手に飛ぶこともある。
  • 悪口を言う人は心の不足や不安を抱えている。聞いているだけでも波動が下がる。
  • 浄化が進むと悪口を言う人との縁は自然に離れていく。悪口をやめるだけで人生は好転する。
願望実現
  • 願望実現は「波動」と「徳」に比例する。波動が高いと努力しなくても自然に叶う。
  • 願いが叶わない最大の原因は前世からの“因縁”。因縁を浄化すると願望実現が一気に進む。
  • 「絶対に叶えたい」という執着は逆効果。手放した瞬間に現実が動き出すことが多い。
  • 自分だけでなく他人の幸せを祈ることで、願いの通り道が広がる。
呪詛（じゅそ）
  • 呪詛とは人に向けられた強い悪意や術が残ったもの。死んでも消えず、前世から持ち越される。
  • 原因不明の頭痛、不安、人間関係の急な崩壊などの原因になることがある。
  • 除霊では消えず、前世の浄化（相手、自分、土地など）でしか根本から解けない。
  • 呪詛をかけた側も苦しみを抱えていた。憎むのではなく、浄化し相手の魂を救うことが大切。
魔物化した神
  • 元々は神だった存在が、長年の怒りや悲しみ（人間からの悪意、忘れ去られた孤独など）で魔物化した状態。
  • 土地の空気が重くなったり、参拝後に体調不良になるなどの影響がある。
  • 敵ではなく救われたい存在。除霊ではなく、神の前世・歴史・土地の浄化が必要。
  • 浄化されると本来の姿に戻り、守護が強くなる。
大切な人の問題を解決する方法
  • 他人の人生の課題を直接解決することはできない。背負うと自分が苦しくなる。
  • 問題の多くは因縁が原因。解決の鍵は「まず自分が浄化すること」。自分が浄化すると相手にも光が届く。
  • 相手のためにできる最も強い行為は「祈り」。コントロールしようとせず、境界線を保って見守る。
先祖供養
  • 先祖の魂を光に戻し、家系の因縁（繰り返される病気や人間関係のトラブル）を軽くする行い。
  • 先祖は子孫を守りたいが、苦しんでいると守れない。供養によって守護が強くなる。
  • 恐れや形式からではなく、感謝と先祖の幸せを祈る気持ちで行うことが正しい供養。日常の中で感謝を思い出すだけでも良い。
霊が家にいる時の対処法
  • 霊がいるのは悪いこととは限らず、浄化のタイミング（因縁が動き出したサイン）であることが多い。
  • 恐れたり、怒って追い払おうとしたりするのはNG。
  • 家の波動を整え（掃除・換気）、自分の波動を整え（感謝・祈り）、霊に「光に戻れますように」と光を送るのが正しい対処法。

形而上学とは

私は「スピリチュアル」という表現が、ご利益・ご都合主義の様に感じ、あまり好きにはなれません。それは既存の宗教に対しても同じ気持ちです。

大元や真理はひとつと捉え、特定の教義への依存や拘りを止め、普遍的な解釈を求める為に「形而上学」という表現が好きです。作法や戒律を守る事より、八百万の神を敬う日本人らしく、人知を超えた世界を認め、自然に謙虚でありたいです。

疑似科学とは

疑似科学とは、科学的な根拠がない、または不十分であるにもかかわらず、科学的であるかのように見せかけた主張や理論の総称です。

科学は仮説と証明で進歩するのであって、間違っているとは言い切れません。今は未だ仮説でも遠い将来証明される可能性があります。

ですので、科学を形而上学の”比喩”として用いる事は賛成ですが、”根拠”として飛びつくのは大変危険な行為と考えます。何処までが証明されて何処までが仮説なのかを見極めるのが重要です。

量子力学とは

古典力学に対し量子力学は、実験が理論を強制的に進化させてきた歴史を持っています。量子力学の“現象”は証明されているが、その“意味”や“背景構造”はまだ解明されていないのが特徴です。

多くのスピリチュアル系疑似科学は「量子脳仮説全般」に該当し、近年急速に発展しているOrch-OR理論に寄りかかる内容だと思いますが、未だ古典的な脳神経科学の方が優位であって、早合点を避けるべき領域です。

確立できれば理論的に大変美しい構造になるのですが、未だ仮説の仮説であることを意識しましょう。
